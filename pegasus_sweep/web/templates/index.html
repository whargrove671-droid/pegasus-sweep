Desktop (this host)

Scans processes, outbound connections, autostart/persistence. Runs on the machine hosting the dashboard — takes ~30–60 s.

idle

Android

Option A — on-device agent. Build & install the agent app (android_agent/); it posts package/process/accessibility data to /api/ingest with the API key. See Agent tab.

Option B — upload an acquisition. Zip of extracted DBs/logs (or an MVT extraction) and the server runs artifact + anomaly scanning.

iOS

iOS exposes no web API for on-device inspection, so the flow is backup upload: the server runs Amnesty MVT (mvt ios decrypt-backup) if installed, then artifact/anomaly scanning on the extracted data. Upload the decrypted/extracted DB set as a zip.

For an unmodified encrypted backup, run mvt locally first (see CLI) — an encrypted iTunes backup requires the device passcode.

Scheduled / remote agents

A desktop agent (agent/agent_desktop.py) you install on machines you own collects a snapshot and POSTs it to /api/ingest with a per-target label. An Android agent (android_agent/) does the same on a phone. Both are opt-in, run locally, and only send the snapshot they gather to your dashboard.

Set PSM_SWEEP_TOKEN on the server and pass the same value to agents. Endpoint: POST /api/ingest with header X-Api-Key and JSON body {"target":"desktop|android","snapshot":{…}}.

Method & honest limits

  • Absence of a match does NOT clear a device. Pegasus rotates C2 infrastructure and implants continuously.
  • The seed IOC set (indicators/pegasus_iocs.yaml) is examples only — refresh from Amnesty MVT / Citizen Lab before trusting a result.
  • Live telemetry is transient — repeat scans across sessions.
  • Process-name matches are the weakest signal (treat alone as low).
  • Full methodology: docs/methodology.md.
